Prova 1 (P1): Equações Diferenciais Ordinárias (EDOs)

Prova 1, Ex 1(a)EDO Linear de 1ª Ordem
Encontre a solução geral de: $xy' - 2y = x^2 \ln x$, com $x > 0$.

Método: Fator Integrante (Equação Linear)

Devemos colocar a EDO na forma padrão $y' + P(x)y = Q(x)$. O fator integrante é $\mu(x) = e^{\int P(x) dx}$. Multiplicando a EDO por $\mu$, o lado esquerdo se torna a derivada do produto $(\mu y)'$.

Passo 1: Forma Padrão
Dividindo por $x$: $y' - \frac{2}{x}y = x \ln x$. (*)
Passo 2: Fator Integrante
$\mu = e^{\int -\frac{2}{x} dx} = e^{-2 \ln x} = x^{-2} = \frac{1}{x^2}$.
Passo 3: Multiplicar a EDO
Multiplicando a eq. (*) por $1/x^2$:
$\frac{1}{x^2}y' - \frac{2}{x^3}y = \frac{\ln x}{x}$.
Isto é equivalente a: $\left( \frac{1}{x^2} y \right)' = \frac{\ln x}{x}$.
Passo 4: Integração
Integrando ambos os lados: $\frac{1}{x^2} y = \int \frac{\ln x}{x} dx$.
Fazendo substituição $u = \ln x, du = \frac{1}{x} dx$:
$\int u du = \frac{u^2}{2} + C = \frac{1}{2}\ln^2 x + C$.
Passo 5: Solução Geral
Isolando $y$: $y = \frac{1}{2}x^2 \ln^2 x + Cx^2$.
Prova 1, Ex 1(b)EDO Exata (Redutível)
Resolva: $3e^{-y} + 4xy^2 + (2x^2y - xe^{-y})y' = 0$

Método: Equação Exata

Verificamos se $P_y = Q_x$. Caso não seja, procuramos um fator integrante. A relação $\frac{P_y - Q_x}{Q}$ se for função apenas de $x$, permite achar um $\mu(x)$.

Passo 1: Verificação de Exatidão
$P(x,y) = 3e^{-y} + 4xy^2 \implies P_y = -3e^{-y} + 8xy$
$Q(x,y) = 2x^2y - xe^{-y} \implies Q_x = 4xy - e^{-y}$
Como $P_y \neq Q_x$, a EDO não é exata.
Passo 2: Encontrar Fator Integrante
$\frac{P_y - Q_x}{Q} = \frac{-3e^{-y} + 8xy - (4xy - e^{-y})}{2x^2y - xe^{-y}} = \frac{4xy - 2e^{-y}}{x(2xy - e^{-y})} = \frac{2(2xy - e^{-y})}{x(2xy - e^{-y})} = \frac{2}{x}$.
Logo: $\frac{d\mu}{dx} = \frac{2}{x}\mu \implies \frac{d\mu}{\mu} = \frac{2}{x}dx \implies \ln \mu = 2\ln x = \ln x^2 \implies \mu = x^2$.
Passo 3: Tornar a EDO Exata
Multiplicando por $\mu = x^2$:
$\underbrace{(3x^2e^{-y} + 4x^3y^2)}_{Novo P} + \underbrace{(2x^4y - x^3e^{-y})}_{Novo Q} y' = 0$.
Testando: $P_y = -3x^2e^{-y} + 8x^3y$. $Q_x = 8x^3y - 3x^2e^{-y}$. Iguais! É exata.
Passo 4: Integração para achar $\phi(x,y)$
$\phi_x = P \implies \phi_x = 3x^2e^{-y} + 4x^3y^2$.
Integrando em $x$: $\phi(x,y) = x^3e^{-y} + x^4y^2 + g(y)$.
Passo 5: Conclusão
Derivando em $y$: $\phi_y = -x^3e^{-y} + 2x^4y + g'(y)$. Igualando a $Q$:
$-x^3e^{-y} + 2x^4y + g'(y) = 2x^4y - x^3e^{-y} \implies g'(y) = 0 \implies g$ é constante.
Solução implícita: $x^3e^{-y} + x^4y^2 = C$.
Prova 1, Ex 2EDO de 2ª Ordem - Coeficientes Constantes
Considere: $y'' + 2\alpha y' + \alpha^2 y = 4e^x$
(a) Solução geral para $\alpha \neq -1$.
(b) Solução do PVI com $\alpha = -1, y(0)=2, y'(0)=-3$.

Item (a): Solução Geral

Passo 1: Solução Homogênea
Equação característica: $r^2 + 2\alpha r + \alpha^2 = 0 \implies (r + \alpha)^2 = 0$.
Raiz dupla: $r_1 = r_2 = -\alpha$.
$y_h(x) = C_1 e^{-\alpha x} + C_2 x e^{-\alpha x}$.
Passo 2: Solução Particular (Método dos Coeficientes a Determinar)
Seja $y_p = A e^x$. ($x$ não colide com raízes homogêneas, pois $\alpha \neq -1 \implies -\alpha \neq 1$).
$y_p' = A e^x, y_p'' = A e^x$.
Passo 3: Substituição
Substituindo: $A e^x + 2\alpha A e^x + \alpha^2 A e^x = 4e^x$.
$A(1 + 2\alpha + \alpha^2) = 4 \implies A(\alpha+1)^2 = 4 \implies A = \frac{4}{(\alpha+1)^2}$.
Passo 4: Solução Geral Completa
$y(x) = y_h + y_p = C_1 e^{-\alpha x} + C_2 x e^{-\alpha x} + \frac{4}{(\alpha+1)^2} e^x$.

Item (b): PVI com $\alpha = -1$

Passo 1: Nova EDO e Solução Homogênea
Com $\alpha = -1$: $y'' - 2y' + y = 4e^x$.
$y_h = C_1 e^x + C_2 x e^x$. Note que a raiz característica agora é $+1$.
Passo 2: Nova Solução Particular
O chute seria $A e^x$, mas colide com $C_1 e^x$. E $A x e^x$ colide com $C_2 x e^x$.
Tentativa correta: $y_p = A x^2 e^x$.
$y_p' = A(2x e^x + x^2 e^x)$.
$y_p'' = A(2 e^x + 4x e^x + x^2 e^x)$.
Passo 3: Substituir e Encontrar A
Substituindo na EDO (*):
$A(2+4x+x^2)e^x - 2A(2x+x^2)e^x + Ax^2e^x = 4e^x$.
$A(2 + 4x + x^2 - 4x - 2x^2 + x^2)e^x = 4e^x \implies 2A e^x = 4e^x \implies A=2$.
Logo $y(x) = C_1 e^x + C_2 x e^x + 2x^2 e^x$.
Passo 4: Condições Iniciais
$y(0) = 2 \implies C_1 = 2$.
$y'(x) = C_1 e^x + C_2(e^x + x e^x) + 4x e^x + 2x^2 e^x$.
$y'(0) = -3 \implies C_1 + C_2 = -3 \implies 2 + C_2 = -3 \implies C_2 = -5$.
Passo 5: Solução do PVI
$y(x) = 2e^x - 5x e^x + 2x^2 e^x$.
Prova 1, Ex 3Redução de Ordem e Variação dos Parâmetros
EDO: $t^2y'' - ty' + y = 3t^2, t > 0$
(a) Verifique $y_1(t)=t$ na homogênea e ache $y_2(t)$ por redução de ordem.
(b) Ache a solução particular e geral.

Item (a): Redução de Ordem

Passo 1: Verificação de $y_1$
$y_1 = t \implies y_1'=1, y_1''=0$. Substituindo em $t^2y''-ty'+y=0$:
$t^2(0) - t(1) + t = 0$. Ok.
Passo 2: Preparação para Fórmula
Dividimos por $t^2$ para achar $P(t)$: $y'' - \frac{1}{t}y' + \frac{1}{t^2}y = 0 \implies P(t) = -\frac{1}{t}$.
Passo 3: Redução de Ordem
$y_2(t) = y_1 \int \frac{e^{-\int P(t) dt}}{y_1^2} dt = t \int \frac{e^{-\int (-1/t) dt}}{t^2} dt$.
$\int -\frac{1}{t}dt = -\ln t \implies e^{\ln t} = t$.
Passo 4: Integração Final
$y_2(t) = t \int \frac{t}{t^2} dt = t \int \frac{1}{t} dt = t \ln t$.
Homogênea: $y_h(t) = C_1 t + C_2 t \ln t$.

Item (b): Variação dos Parâmetros

Passo 1: Wronskiano
$y_1 = t, y_2 = t \ln t$
$W = \det \begin{pmatrix} t & t \ln t \\ 1 & \ln t + 1 \end{pmatrix} = t(\ln t + 1) - t \ln t = t \ln t + t - t \ln t = t$.
Passo 2: Forma Padrão de $g(t)$
A EDO é $y'' - \frac{1}{t}y' + \frac{1}{t^2}y = 3$. Logo, a função fonte $g(t) = 3$.
Passo 3: Aplicação da Fórmula
$y_p = -y_1 \int \frac{y_2 g}{W} dt + y_2 \int \frac{y_1 g}{W} dt$
$y_p = -t \int \frac{t \ln t \cdot 3}{t} dt + t \ln t \int \frac{t \cdot 3}{t} dt$.
$y_p = -3t \int \ln t dt + 3t \ln t \int dt$.
Passo 4: Resolução das Integrais
$\int \ln t dt = t \ln t - t$
$\int dt = t$
$y_p = -3t(t \ln t - t) + 3t \ln t (t) = -3t^2 \ln t + 3t^2 + 3t^2 \ln t = 3t^2$.
Passo 5: Solução Geral
$y(t) = C_1 t + C_2 t \ln t + 3t^2$.

Prova 2 (P2): Transformada de Laplace

Prova 2, Ex 1Transformadas Direta e Inversa

Item (a): Direta $f(t) = e^{-2t} \cos(\pi t) + t \sin(t)$

Passo 1: Teorema da Translação
A transformada de $\cos(\pi t)$ é $\frac{s}{s^2 + \pi^2}$. Com $e^{-2t}$, transladamos $s \to s+2$:
$\mathcal{L}\{e^{-2t} \cos(\pi t)\} = \frac{s+2}{(s+2)^2 + \pi^2}$.
Passo 2: Derivada da Transformada
Para $t \sin(t)$, usamos $\mathcal{L}\{t f(t)\} = -F'(s)$.
$\mathcal{L}\{\sin t\} = \frac{1}{s^2+1}$. Derivando: $-\frac{d}{ds}\left(\frac{1}{s^2+1}\right) = -\left(\frac{-2s}{(s^2+1)^2}\right) = \frac{2s}{(s^2+1)^2}$.
Passo 3: Conclusão
$F(s) = \frac{s+2}{(s+2)^2 + \pi^2} + \frac{2s}{(s^2+1)^2}$, para $s > 0$.

Item (b): Inversa $F(s) = \frac{s}{(s-1)^2 + 4}$

Passo 1: Ajuste Algébrico
Devemos montar $s-1$ no numerador para coincidir com o denominador.
$\frac{s}{(s-1)^2+4} = \frac{s-1+1}{(s-1)^2+4} = \frac{s-1}{(s-1)^2+4} + \frac{1}{(s-1)^2+4}$.
Passo 2: Identificação de Tabelas
O 1º termo é $\mathcal{L}\{e^t \cos(2t)\}$.
O 2º termo precisa do fator $2$ no numerador: $\frac{1}{2}\frac{2}{(s-1)^2+4}$, que é $\frac{1}{2}\mathcal{L}\{e^t \sin(2t)\\}$.
Passo 3: Conclusão
$\mathcal{L}^{-1}\{F(s)\} = e^t \cos(2t) + \frac{1}{2} e^t \sin(2t)$.
Prova 2, Ex 2EDO por Laplace (PVI Simples)
$y'' + y = t, \quad y(0)=0, y'(0)=0$.
Passo 1: Aplicação de Laplace na EDO
$\mathcal{L}\{y''\} + \mathcal{L}\{y\} = \mathcal{L}\{t\}$
$[s^2 Y(s) - sy(0) - y'(0)] + Y(s) = \frac{1}{s^2}$.
Passo 2: Condições Iniciais
Substituindo $y(0)=0, y'(0)=0$, ficamos com: $(s^2+1)Y(s) = \frac{1}{s^2}$.
Passo 3: Isolamento e Frações Parciais
$Y(s) = \frac{1}{s^2(s^2+1)}$. Pela forma: $\frac{1}{s^2(s^2+1)} = \frac{1}{s^2} - \frac{1}{s^2+1}$.
Passo 4: Inversa de Laplace
$y(t) = \mathcal{L}^{-1}\left\{\frac{1}{s^2} - \frac{1}{s^2+1}\right\} = t - \sin t$.
Prova 2, Ex 3EDO com Função Degrau (Heaviside)
$y'' + 9y = g(t)$, onde $g(t) = t$ ($0 \le t < 1$) e $1$ ($t \ge 1$), com $y(0)=1, y'(0)=0$.
Passo 1: Expressar $g(t)$ em Degraus
$g(t) = t + (1-t)u_1(t) = t - (t-1)u_1(t)$.
Passo 2: Transformada de $g(t)$
$\mathcal{L}\{g(t)\} = \frac{1}{s^2} - \frac{e^{-s}}{s^2}$.
Passo 3: Laplace na EDO
$\mathcal{L}\{y'' + 9y\} = [s^2 Y - sy(0) - y'(0)] + 9Y = s^2 Y - s + 9Y$
$(s^2+9)Y - s = \frac{1}{s^2} - \frac{e^{-s}}{s^2}$.
Passo 4: Isolar $Y(s)$
$(s^2+9)Y = s + \frac{1}{s^2} - \frac{e^{-s}}{s^2}$
$Y(s) = \frac{s}{s^2+9} + \frac{1}{s^2(s^2+9)} - \frac{e^{-s}}{s^2(s^2+9)}$.
Passo 5: Frações Parciais e Inversa
Note que $\frac{1}{s^2(s^2+9)} = \frac{1}{9}\left[\frac{1}{s^2} - \frac{1}{s^2+9}\right]$.
$Y(s) = \frac{s}{s^2+9} + \frac{1}{9}\left[\frac{1}{s^2} - \frac{1}{3}\frac{3}{s^2+9}\right] - e^{-s}\frac{1}{9}\left[\frac{1}{s^2} - \frac{1}{3}\frac{3}{s^2+9}\right]$.
$y(t) = \cos(3t) + \frac{1}{9}\left[t - \frac{1}{3}\sin(3t)\right] - \frac{1}{9}u_1(t)\left[(t-1) - \frac{1}{3}\sin(3(t-1))\right]$.
Prova 2, Ex 4Demonstração: Mudança de Escala
Dado $\lambda > 0$, prove que $\mathcal{L}\{f(\lambda t)\} = \frac{1}{\lambda} F\left(\frac{s}{\lambda}\right)$.
Passo 1: Definição Integral
$\mathcal{L}\{f(\lambda t)\} = \int_0^\infty e^{-st} f(\lambda t) dt$.
Passo 2: Mudança de Variável
Seja $\tau = \lambda t \implies dt = \frac{d\tau}{\lambda}$.
Limites não mudam pois $\lambda > 0$.
Passo 3: Substituição
$= \int_0^\infty e^{-s(\tau/\lambda)} f(\tau) \frac{d\tau}{\lambda}$.
Passo 4: Finalização
$= \frac{1}{\lambda} \int_0^\infty e^{-(s/\lambda)\tau} f(\tau) d\tau = \frac{1}{\lambda} F\left(\frac{s}{\lambda}\right)$.

Prova 3 (P3): Séries de Potências

Prova 3, Ex 2Série Geométrica
Verifique se $\sum_{k=1}^\infty (3/\pi)^k$ converge e ache a soma.
Passo 1: Teste da Raiz (Opcional, mas feito)
$L = \lim_{n\to\infty} \sqrt[n]{(3/\pi)^n} = 3/\pi$. Como $3 < \pi$, $L < 1$. Logo, converge.
Passo 2: Soma da Série Geométrica
É uma série geométrica de razão $r = 3/\pi$.
A soma total de $k=0$ a $\infty$ é $\frac{1}{1 - 3/\pi} = \frac{\pi}{\pi-3}$.
Passo 3: Ajuste de Índices
A série pedida começa em $k=1$.
$\sum_{k=1}^\infty (3/\pi)^k = \sum_{k=0}^\infty (3/\pi)^k - (3/\pi)^0 = \frac{\pi}{\pi-3} - 1 = \frac{\pi - (\pi-3)}{\pi-3} = \frac{3}{\pi-3}$.
Prova 3, Ex 3Intervalo de Convergência e Derivada
$f(x) = \sum_{n=1}^\infty \frac{1}{n}(3x-2)^n$. (a) Valores de convergência. (b) Derivada $f^{(2026)}(2/3)$.

Item (a): Raio e Intervalo

Passo 1: Reescrever Centro
$\sum \frac{1}{n} 3^n (x - 2/3)^n$. Logo, $a_n = \frac{3^n}{n}$ e centro $x_0 = 2/3$.
Passo 2: Raio via Razão
$R = \lim \left|\frac{a_n}{a_{n+1}}\right| = \lim \frac{3^n}{n} \frac{n+1}{3^{n+1}} = \lim \frac{1}{3}\frac{n+1}{n} = \frac{1}{3}$.
Intervalo preliminar: $(2/3 - 1/3, 2/3 + 1/3) = (1/3, 1)$.
Passo 3: Teste nos Extremos
Para $x = 1/3$: $\sum \frac{1}{n}(3(1/3)-2)^n = \sum \frac{(-1)^n}{n}$ (Série Harmônica Alternada, converge).
Para $x = 1$: $\sum \frac{1}{n}(3(1)-2)^n = \sum \frac{1}{n}$ (Série Harmônica, diverge).
Intervalo: $[1/3, 1)$.

Item (b): Derivada Pontual

Passo 1: Fórmula de Taylor
Sabemos que o coeficiente é dado por $\frac{f^{(n)}(x_0)}{n!} = a_n$.
Passo 2: Aplicação
$\frac{f^{(n)}(2/3)}{n!} = \frac{3^n}{n} \implies f^{(n)}(2/3) = n! \frac{3^n}{n} = (n-1)! 3^n$.
Passo 3: Resultado
Para $n=2026$: $f^{(2026)}(2/3) = (2025)! 3^{2026}$.
Prova 3, Ex 4Cota do Raio em EDO
EDO: $(1+x)y'' - x^2y' + (1-x)y = 0$. Avaliar em $x_0=1$.
Passo 1: Forma Padrão
$y'' - \frac{x^2}{1+x}y' + \frac{1-x}{1+x}y = 0 \implies P(x) = -\frac{x^2}{1+x}, Q(x) = \frac{1-x}{1+x}$.
Passo 2: Ponto Ordinário
As funções são racionais. Em $x_0 = 1$, o denominador $1+x = 2 \neq 0$. Logo são analíticas, $x_0 = 1$ é ponto ordinário.
Passo 3: Cota do Raio
Raiz do denominador: $x = -1$. A distância do centro $x_0 = 1$ até a raiz singular $x = -1$ é $R_S = |1 - (-1)| = 2$.
Logo, o raio de convergência é garantidamente no mínimo 2 ($R \ge 2$).
Prova 3, Ex 5Solução de EDO em Séries
$y'' - 2xy' = 0$. Ache relação de recorrência e soluções em séries em torno de $x_0=0$.
Passo 1: Séries
$y = \sum_{n=0}^\infty a_n x^n, \quad y' = \sum_{n=1}^\infty n a_n x^{n-1}, \quad y'' = \sum_{n=2}^\infty n(n-1) a_n x^{n-2}$.
Passo 2: Substituição
$\sum_{n=2}^\infty n(n-1)a_n x^{n-2} - 2x \sum_{n=1}^\infty n a_n x^{n-1} = 0$.
$\sum_{n=2}^\infty n(n-1)a_n x^{n-2} - \sum_{n=1}^\infty 2n a_n x^n = 0$.
Passo 3: Ajuste de Índices
Na 1ª soma fazemos $k = n-2 \implies n = k+2$. Na 2ª fazemos $k = n$.
$\sum_{k=0}^\infty (k+2)(k+1)a_{k+2} x^k - \sum_{k=1}^\infty 2k a_k x^k = 0$.
Passo 4: Relação de Recorrência
Isolando termo para $k=0$: $2a_2 = 0 \implies a_2 = 0$.
Para $k \ge 1$: $(k+2)(k+1)a_{k+2} - 2k a_k = 0 \implies a_{k+2} = \frac{2k}{(k+2)(k+1)} a_k$.
Passo 5: Solução Geral
Termos pares: $a_4=0, a_6=0 \implies a_{2n}=0$ para $n \ge 1$. $a_0$ é livre ($y_1(x)=1$).
Termos ímpares: $a_3 = \frac{2}{3\cdot 2}a_1, a_5 = \frac{2^2 \cdot 3}{5!}a_1 \implies a_{2n+1} = \frac{2^n \cdot 1 \cdot 3 \dots (2n-1)}{(2n+1)!} a_1$.
Solução: $y(x) = a_0 + a_1 \left( x + \sum_{n=1}^\infty \frac{2^n \cdot 1\cdot 3\dots(2n-1)}{(2n+1)!} x^{2n+1} \right)$.
